# chess-game

Browser-based chess: React 19 + TypeScript + Vite, Jotai for state, no
backend.

Before making changes, read the specs in [specs/](specs/):

- [specs/code-style.md](specs/code-style.md) — naming, formatting,
  readability, testability, and structural conventions used in this
  codebase.
- [specs/architecture.md](specs/architecture.md) — state management, the
  move-validation pipeline, and the turn/check/checkmate flow.
- [specs/commit-messages.md](specs/commit-messages.md) — commit message
  format (Conventional Commits).

These are living documents — when a change makes one of them inaccurate,
update it in the same commit.
